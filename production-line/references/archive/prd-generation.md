# 📋 創意宣言生成指南 (Creative Manifesto)

本文件說明在 Phase 1 產出的「創意宣言」結構。這是一份給代理人自己的靈感藍圖，用來定調隨後的建站方向。

與傳統的 PRD 不同，這份宣言**不包含**死板的頁面清單或硬性技術約束。它只專注於：**品牌是誰、長什麼樣子、帶給人什麼感受。**

---

## 創意宣言的 4 個核心要素

在一鍵建站的 Phase 1 結束時，你必須輸出以下格式的宣言：

```markdown
# 🎨 創意宣言: [Brand Name]

## 1. 品牌靈魂 (The Soul)
- **品牌名稱**: [英文品牌名]
- **品牌標語**: [12 字以內的英文標語]
- **商品主題**: [例如：手工蠟燭、高階機械鍵盤]
- **情感屬性**: [例如：奢華精品感、街頭潮流感]
- **品牌故事**: [一句話描述創立初衷與堅持]

## 2. 美學基底 (The Aesthetic)
- **DNA 混血**: [主 DNA-## (Family X) × 副 DNA-## (Family Y)，見 real-ecommerce-dna.md]
- **UI UX Pro Max 指引**: [簡述 Python 腳本回傳的核心 Pattern / Style]
- **變異風格名**: [你為這次融合命名的專屬風格，例如 "Midnight Velvet Brutalism"]

## 3. 視覺系統 (The Visuals)
- **色彩計畫**:
  - Primary: [#HEX] (用途說明)
  - Secondary: [#HEX] (用途說明)
  - Accent/CTA: [#HEX] (用途說明)
- **字體配對**: [Heading Font] + [Body Font] (附上 Google Fonts 連結)
- **特定視覺元素**: [例如：大圓角、粗黑邊框、玻璃擬物光澤、極簡留白]

## 4. 關鍵版型與差異化 (Layout & Differentiation)
- **英雄排版 (Hero)**: [全幅背景？左右分割？字體主導型 (Typographic Heavy)？——**請務必避開平庸的置中排版**]
- **結構簽名 (Structural Signature)**: [明確定義一個破壞常規的排版規則，例如：「本站禁用頂部 Navbar，改用底部懸浮選單」或「連續 5 個區塊的左右比例必須是不對稱的 65/35」]
- **組件解構 (Component Deconstruction)**: [說明 ProductCard 的特別實作方式，例如：「極大粗黑框線」、「移除邊界改用圓形遮罩」、「圖片在左文字在右的書籤比例」]
- **微互動靈魂**: [符合美學引擎的專屬動效，例如「硬切換無漸變」或「流體拉伸」]
```

---

## 接下來的事：完全授權

當你輸出這份宣言後，**你就擁有了 100% 的前端實作自由**。

你不必受限於預設的 Component 結構，也不用被迫刻板地實作某個特定的 Hover 效果。
只要最終能交付 4 個核心頁面（首頁、列表、詳情、購物車 Drawer），並且**視覺上忠於你的創意宣言**，剩下的頁面要怎麼長、動畫要怎麼跑，全都由你這個「高級前端設計師」說了算！
