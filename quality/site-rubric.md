# 好電商站 Rubric v1

> 來源：實際比對自家產出的站點歸納而成，不是抄現成的評分表。
>
> 校準用的三個樣本刻意選成兩正一反，且兩個正面樣本走完全不同的風格
> （一個是街頭粗獷風的潮牌站，一個是傳統中式風格的靜態站），
> **避免這份標準只認得一種美感**。
>
> 反面樣本是自家早期產出中最像「模板換色」的那一個。
> 三個樣本都不在本 repo 內，因為它們是校準用的內部參照，不是交付物。

## 怎麼用這份 Rubric
- 評審用 Playwright 開站截圖，看「使用者真正會看到的畫面」打分。程式碼漂不漂亮不算數。
- 至少截四張：首頁、商品詳情、結帳、行動版（< 768px）。
- 每個維度 0 到 5 分。原創性、設計品質、品牌文案三個維度權重 x2，因為這三個是 AI 最會出包、最容易露餡的地方。
- **校準測試**：這份標準套到反面樣本應該大量扣分，套到兩個正面樣本應該通過。跑起來若不是這個結果，代表標準還沒抓到重點，回來改標準而不是改分數。

---

## 維度一：原創性（權重 x2）
抓「一眼看出是 AI 套版」的死穴。出現任一條禁令，本維度直接壓到 2 分以下。

禁令：
- 主視覺字體禁用 Inter / Roboto / Arial / 系統預設字當識別。識別要靠一個有個性的 display 字體（街頭粗獰風樣本用 Oswald + Teko）。Inter 只能當內文。
- 禁用 Playfair Display + Inter 這組「假高級」AI 預設配對。
- hero 主視覺禁止用模糊漸層光暈 blob 當主角（blur-3xl + rounded-full 那種）。低透明度細緻紋理或微漸層襯底可以（中式傳統風樣本 body 用 0.05 透明度漸層加噪點當底就 OK），差別在「它是主角還是襯底」。
- 主標禁用漸層裁字（bg-clip-text gradient text）。
- 全站禁止只用 rounded-full 膠囊鈕加 rounded-2xl 卡片這種預設圓角交差。造型要刻意（街頭粗獰風樣本用直角加偏移硬陰影 shadow-[4px_4px_0]）。

好的樣子：截圖遮掉 logo，旁人也講得出這站的風格名。風格可以是任何方向，只要刻意：街頭粗獰風樣本是街頭 brutalist，中式傳統風樣本是宮廷中式（紅金配色、祥雲、☯、Noto Serif TC）。講不出來、只能說「一個普通深色漸層網站」就是沒過。

## 維度二：設計品質（權重 x2）
顏色、字體、排版有沒有一起撐出一個獨特氛圍與識別。

禁令：
- 配色禁止套自動生成的 50-950 三色階就交差。要刻意的「主色 + 中性底 + 強調色」克制搭配（街頭粗獰風樣本：橘 #F97316 + 近黑 #09090B + 白）。
- 標題與內文要有明顯字級階層與字體對比（街頭粗獰風樣本：標題全大寫 Oswald，內文 Inter，標籤用 mono）。
- 配色最好有「意義」，不要只是好看。中式傳統風樣本把色票命名成宮廷紅 #B91C1C、帝王金 #D4AF37、水墨黑 #1A1A1A，每個色都對應品牌概念。
- 中文站排版要用合適的 CJK 字體（中式傳統風樣本用 Noto Serif TC + Noto Sans TC），不要拿一個純拉丁字體硬撐中文。

好的樣子：截圖遮掉 logo，還是感覺得到「這牌子是誰、賣給誰」。

## 維度三：品牌文案（電商專屬，權重 x2）
抓文案的 AI 味，沿用既有的反 AI 寫作規則。

禁令：
- 禁用破折號把兩個短句黏起來當節奏。
- 禁用「不是 A，而是 B」句型。
- 禁堆空形容詞（self-sustaining、meticulously crafted、serenity、game changer 這類）。
- 禁假評論：「名字首字母縮寫 + 美國城市州」格式（Elena M., Portland OR）。要嘛接真實評論資料，要嘛不放。

好的樣子：有觀點、有具體畫面的品牌聲音（街頭粗獰風樣本：「forged on the cracked asphalt of East Coast courts… every pickup game like Game 7 of the Finals」）。

## 維度四：商業真實感（電商專屬）
是能真的買東西的站，不是單頁 demo。

檢查點：
- 多頁齊全：商品列表、商品詳情、購物車、結帳、會員登入、願望清單、法務頁（隱私／條款／運送）。
- 商品資料含：尺寸、顏色、評分、細節規格。
- 庫存數字與「原價／特價」**有真實依據才算分**：庫存要對得上後端的實際數量，劃線原價要有 30 天內真實售價當基準。編出來的「只剩 3 件」與沒有基準的劃線價**不但不加分，還是不得交付的違規**，會被品質檢查的第八層（合規閘門，見 [`production-line/SKILL.md`](../production-line/SKILL.md)）攔下（英國 DMCCA）。做不到就不要放，少放不扣這一維的分。
- 真的能加購、改數量、走完結帳。

對照：反面樣本只有單頁加一個 cart store，沒詳情沒結帳，這維度低分。街頭粗獰風樣本全有，高分。

## 維度五：技術執行
- 行動版 < 768px 不破版、圖不變形。
- hover 與互動有回饋，但不浮誇。
- Lighthouse 行動版 performance > 80，主控台無 error。
- 同類標題字級、間距、對比保持一致。

## 維度六：可用性
- 主要 CTA 一眼找得到。
- 首頁到結帳 ≤ 3 次點擊。
- 價格、加入購物車、庫存狀態清楚易讀。

## 配套 /goal prompt（直接拿去跑）

```
/goal 這個電商網站要通過《好電商站 Rubric v1》全部六個維度。原創性、設計品質、品牌文案這三個權重維度每個都要 ≥ 4 分（滿分 5），其餘維度 ≥ 3 分，且禁令清單一條都不能出現。

驗證方式：每輪結束用 Playwright 開站截圖（首頁、商品詳情、結帳、行動版各一張），照 Rubric 逐維度自評打分，把分數和扣分原因寫進對話。

限制：只動這個專案的前端程式碼與樣式，不要改資料結構、API、後端。

每輪記錄：這輪改了什麼、各維度分數、最該修的下一個點。

停止條件：全部維度達標就停；或跑滿 20 輪、或同一個問題卡 3 輪都解不掉就停，回報卡在哪、需要我給什麼。
```
